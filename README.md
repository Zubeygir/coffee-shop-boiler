# Zubo Cafe

Single-page coffee shop demo built around a scroll-driven 3D takeaway cup.
Next.js 16 · React 19 · Tailwind CSS v4 · three.js (React Three Fiber).

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

`.env.local` holds a single variable, `NEXT_PUBLIC_SITE_URL` (used for canonical URLs, sitemap and Open Graph).
